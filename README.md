# Trunic
You can write any english phrases in Trunic automatically


In order to use my programme you'll have to install some python library.
In your terminal type : 

pip install phonemizer
winget install eSpeak-NG.eSpeak-NG

Now you can write in Trunic !
In order to write a text : launch the programm. Then enter your text. Only english will be well translated in Trunic.
